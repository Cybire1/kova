# Assets

- `device-frame.png`: AppLaunchFlow blank flat device frame, downloaded from
  https://www.applaunchflow.com/mockups/iphone17-3d-flat.png
  Source and commercial-use terms:
  https://www.applaunchflow.com/tools/mockup-generator/iphone-16
  This is AppLaunchFlow's frame artwork, not official Apple artwork. The source
  identifies the chassis as its iPhone 17 Pro Max-style frame. Its screen opening
  is composed with the existing Kova capture without stretching that capture.
- `app-icon.png`: copied from Kova's own `apps/mobile/assets/brand/icon.png`.
- `lockup.svg`: Kova's own `film/public/demo/kova-lockup.svg`.
- Screen: existing Kova app capture `private/sam/01-home-before.png`.
  `screen-master.png` is that same capture, prefiltered with Lanczos to its
  display size in the 4K master so the browser does not apply a soft minification
  filter to the original capture. Its content and aspect ratio are preserved.

Apple's separate marketing-artwork agreement was not accepted on the user's
behalf. No Apple artwork from the downloaded disk image is used.
